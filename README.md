# 🛡️ Let'sDefend Lab Investigations

Welcome to my SOC Analyst portfolio!

This repository contains hands-on security investigations completed on the **Let'sDefend** platform. Each investigation simulates real-world Security Operations Center (SOC) scenarios, where I analyze security alerts, investigate suspicious activities, validate threats, identify Indicators of Compromise (IoCs), and document my findings using industry-standard incident response methodologies.

## 📌 Purpose

The purpose of this repository is to document my hands-on SOC investigations, demonstrate practical cybersecurity skills, and showcase my approach to alert triage, threat analysis, malware investigation, IoC extraction, and incident documentation.
